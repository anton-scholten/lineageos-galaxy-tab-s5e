Unofficial **LineageOS 23.2 (Android 16)** for the Samsung Galaxy Tab S5e: a full ROM plus a backport of the ExyHyperBrick 4.9 eBPF kernel series.
This is not an official LineageOS build; please don't report its bugs to the LineageOS team.

| Model | Codename | Status |
|---|---|---|
| SM-T720 / T720N (Wi-Fi) | `gts4lvwifi` | ✅ Works (daily use on the developer's SM-T720) |
| SM-T725 / T725C / T725N / T727* (LTE) | `gts4lv` | 🔨 Built, **untested** — testers wanted |

**What's new since 20261008**
- **Charging status is instant again.** Plugging in or unplugging the charger now updates the battery icon, plays the charging sound and wakes the screen within a fraction of a second. Before, Android noticed it 8 s to almost 4 minutes late (longest when the tablet was idle), so it looked like nothing happened.
  Cause: a kernel BPF bug from the eBPF backport made Android 16's battery-event filter drop every charger event. Fixed in the kernel (same fix as upstream Linux [`e6a18d36118b`](https://git.kernel.org/torvalds/c/e6a18d36118b)).
- **Thermal sensors:** the thermal HAL can now read the Samsung AP, PA and back-cover thermistors (they were blocked by SELinux).

**Files per model** (never mix codenames):
- `lineage-23.2-20261014-UNOFFICIAL-<codename>.zip`: the ROM, sideloaded from recovery
- `recovery-20261014-<codename>.img`: the 23.2 recovery for this build. **Required** for a new install: the 22.2 recovery can't install 23.2
- `vbmeta-20261014-<codename>.img`: only needed when coming from Samsung stock (first unlock)
- `SHA256SUMS`: check your downloads with `sha256sum -c SHA256SUMS --ignore-missing`

**Updating from an earlier build of this unofficial 23.2 (e.g. 20261008): no data is erased.** Same signing keys, so do **not** factory reset or format data, even if you also flash the new recovery.
Optionally flash `recovery-20261014-<codename>.img` (samloader/Odin/Heimdall, `RECOVERY`) → boot to recovery → *Apply update → Apply from ADB* → `adb sideload` the zip → reboot. Installed Google Apps are kept.

**New install:** follow the [install guide](https://github.com/anton-scholten/lineageos-galaxy-tab-s5e#install--upgrade). ⚠️ A clean install erases all data.
In short: flash the recovery (samloader/Odin, `RECOVERY`) → *Factory reset → Format data* (also formats `/metadata` on the OMR
partition, which Android 16 needs) → sideload the zip → optionally sideload [MindTheGapps 16.0.0 arm64](https://github.com/MindTheGapps/16.0.0-arm64/releases/latest) → reboot.
Coming from official LineageOS 22.2 or Samsung stock still needs this clean install (different signing keys).

**Works on SM-T720:** Wi-Fi, hotspot, per-app data usage (eBPF), audio, microphone, camera, Google Apps, charging indicator and charging sound.
**Known issues:** screen casting fixed in the build but not yet confirmed on a receiver; no ANT+; LTE: no VoLTE/VoWiFi.

**LTE testers:** before flashing, run `adb shell ls -l /dev/block/by-name/omr` from any recovery and report the result.
