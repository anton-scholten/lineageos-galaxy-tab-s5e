Unofficial **LineageOS 24 (Android 17)** for the Samsung Galaxy Tab S5e. Install guide, status and known issues: [README](https://github.com/anton-scholten/lineageos-galaxy-tab-s5e#readme).

**Coming from 24.0-20261022, 24.0-20261026, 24.0-20261105, 24.0-20261109 or 24.0-20261116: update over the air** (*Settings → System → Updater*), no data is erased.

**What's new since 2026-11-16**
- **Quick Settings volume tile no longer interrupts videos**: tapping it shows the volume panel over the current app. Before, it could send YouTube into picture-in-picture or to the background.
- **Faster memory compression**: compressed swap (zram) uses LZ4 instead of LZO.
- Latest LineageOS updates.

Kernel `4.9.337-g29d0d71a4d35`, device tree `f896da9`. Fixes owed upstream: [UPSTREAM.md](https://github.com/anton-scholten/lineageos-galaxy-tab-s5e/blob/main/UPSTREAM.md).
