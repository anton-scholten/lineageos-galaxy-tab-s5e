Unofficial **LineageOS 23.2 (Android 16)** for the Samsung Galaxy Tab S5e: a full ROM plus a backport of the ExyHyperBrick 4.9 eBPF kernel series.
This is not an official LineageOS build; please don't report its bugs to the LineageOS team.

| Model | Codename | Status |
|---|---|---|
| SM-T720 / T720N (Wi-Fi) | `gts4lvwifi` | ✅ Works (daily use on the developer's SM-T720) |
| SM-T725 / T725C / T725N / T727* (LTE) | `gts4lv` | 🔨 Built, **untested** — testers wanted |

**What's new since 2026-10-14**
- **Bluetooth pairing fixed.** Pairing with phones failed and Bluetooth turned itself off and on (reported with an iPhone used for CarPlay); speakers were not affected.
  Cause: this tablet's Bluetooth chip mishandles one LE connection command. The device has always told the Bluetooth stack to avoid it, but the Android 16 stack stopped reading that setting. Restored in the stack.
  Tested: pairing and receiving files from an Android phone. **iPhone/CarPlay testers wanted.**
- **Always-on display updates again.** The clock, charging status and new notifications now appear on the always-on display; before, it froze until the screen was woken.
- **Tablet defaults** (new installs only): auto-rotate and auto-brightness on, device name "Galaxy Tab S5e" instead of "SM-T720".

**Files per model** (never mix codenames):
- `lineage-23.2-20261016-UNOFFICIAL-<codename>.zip`: the ROM, sideloaded from recovery
- `recovery-20261016-<codename>.img`: the 23.2 recovery for this build. **Required** for a new install: the 22.2 recovery can't install 23.2
- `vbmeta-20261016-<codename>.img`: only needed when coming from Samsung stock (first unlock)
- `SHA256SUMS`: check your downloads with `sha256sum -c SHA256SUMS --ignore-missing`

**Updating from an earlier build of this unofficial 23.2 (20261008, 20261014): no data is erased.** Same signing keys, so do **not** factory reset or format data, even if you also flash the new recovery.
Optionally flash `recovery-20261016-<codename>.img` (samloader/Odin/Heimdall, `RECOVERY`) → boot to recovery → *Apply update → Apply from ADB* → `adb sideload` the zip → (optional) sideload MindTheGapps → reboot.

**New install:** follow the [install guide](https://github.com/anton-scholten/lineageos-galaxy-tab-s5e#install--upgrade). ⚠️ A clean install erases all data.
In short: flash the recovery (samloader/Odin, `RECOVERY`) → *Factory reset → Format data* (also formats `/metadata` on the OMR
partition, which Android 16 needs) → sideload the zip → (optional) sideload [MindTheGapps 16.0.0 arm64](https://github.com/MindTheGapps/16.0.0-arm64/releases/latest) → reboot.
Coming from official LineageOS 22.2 or Samsung stock still needs this clean install (different signing keys).

**Bluetooth after a reinstall:** a phone that was paired with the tablet before keeps the old pairing and then refuses ("pairing rejected" / "failed to connect"). *Forget* the tablet on the phone first, then pair again.

**Works on SM-T720:** Wi-Fi, hotspot, per-app data usage (eBPF), audio, microphone, camera, Google Apps, charging indicator and charging sound, Bluetooth audio, pairing and file transfer, always-on display.
**Known issues:** screen casting fixed in the build but not yet confirmed on a receiver; no ANT+; LTE: no VoLTE/VoWiFi.

**LTE testers:** before flashing, run `adb shell ls -l /dev/block/by-name/omr` from any recovery and report the result.
