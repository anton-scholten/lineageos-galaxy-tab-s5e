[SIZE=4]Unofficial LineageOS 24 (Android 17) and 23.2 (Android 16) for the Samsung Galaxy Tab S5e[/SIZE]

[SIZE=3]SM-T720 / T720N (gts4lvwifi) · SM-T725 / T725C / T725N / T727* (gts4lv)[/SIZE]


Android 16/17 need kernel features a 4.9 kernel doesn't have (mainly modern eBPF).

This port has two parts: a [B]kernel backport[/B] (the ExyHyperBrick 4.9 eBPF series, about 2,450 commits, plus EROFS for Google Play services) and a [B]full ROM[/B] (device tree, blobs and fixes for Android 16/17).

[B]LineageOS 24 is the recommended version.[/B] 23.2 stays available.

This is an [B]unofficial[/B] build made with AI to speed up the process.

It is not supported by the LineageOS team, so please don't report its bugs to them.


[SIZE=5][B]Status[/B][/SIZE]

[LIST]

[*][B]SM-T720 (Wi-Fi):[/B] ✅ Works on my own tablet, no bugs so far.

[*][B]SM-T725 / T727 (LTE):[/B] ✅ Works on 23.2 and 24, including mobile data (reported by users). Known issue: Dolby Atmos.

[/LIST]


[SIZE=5][B]Known issues[/B][/SIZE]

[LIST]

[*]Screen casting (Miracast): fixed in the build, not yet confirmed on a receiver.

[*]ANT+ is not available.

[*]LTE models: no VoLTE / VoWiFi (calls fall back to 2G/3G), Dolby Atmos unreliable, SIM on/off switch greyed out (Samsung's modem driver doesn't support it).

[/LIST]


[SIZE=5][B]Installation and updates[/B][/SIZE]

⚠️ [B]A first install is a clean install, which erases all data on the tablet.[/B] Back up first, and remove your Google account from the tablet (Factory Reset Protection).

Full steps: [URL]https://github.com/anton-scholten/lineageos-galaxy-tab-s5e#install--upgrade[/URL]

In short: flash the recovery of the version you install (samloader/Odin/Heimdall, RECOVERY) → Factory reset → Format data → Apply update → Apply from ADB → sideload the ROM zip → (optional) sideload MindTheGapps (17.0.0 for 24, 16.0.0 for 23.2, arm64) [B]before the first boot[/B] → reboot.

[B]Updates arrive over the air[/B] from build 20261019 on: Settings → System → Updater, no data is erased. Coming from an older build of this ROM, from official LineageOS 22.2 or from 23.2 to 24 still needs the clean install.

[B]Never mix codenames:[/B] gts4lvwifi files are for SM-T720/T720N only, gts4lv files for the LTE models only.
