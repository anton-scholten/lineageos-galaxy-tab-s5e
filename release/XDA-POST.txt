[SIZE=5][B]What is this?[/B][/SIZE]
Official LineageOS support for the Tab S5e ends at 22.2 (Android 15). Android 16 needs kernel features that the tablet's Linux 4.9 kernel doesn't have, above all a modern eBPF stack: netd and the network stack won't start without it.

This project is two things:
[LIST]
[*][B]A kernel backport.[/B] The ExyHyperBrick 4.9 eBPF series by krazey (built for the Galaxy S9) is ported onto the Tab S5e (SDM670) kernel: about 2,450 commits, cherry-picked with every original author kept. It brings eBPF up to the Linux 5.15 level, plus close_range, epoll_pwait2, FUSE-BPF, userfaultfd, uclamp and PSI. It also adds one fix of our own: SELinux policy loading for msm-4.9 kernels running Android 16 policy.
[*][B]A full ROM.[/B] The LineageOS 23.2 device tree adapted for Android 16: cgroup setup for a uclamp kernel, lmkd on PSI, Samsung's unused OMR partition as /metadata (needed for Android 16's feature-flag storage, the same approach official LineageOS uses on the Galaxy S10), uclamp power hints, and a shim that brings back screen casting.
[/LIST]
This is an [B]unofficial[/B] build. It is not supported by the LineageOS team, so please don't report its bugs to them.

[SIZE=5][B]Installation[/B][/SIZE]
⚠️ [B]A clean install is required. This erases all data on the tablet.[/B] Back up first, and remove your Google account from the tablet (Factory Reset Protection).
[LIST=1]
[*]Coming from Samsung stock: unlock the bootloader and flash vbmeta first, exactly as in the [URL='https://wiki.lineageos.org/devices/gts4lvwifi/install/']official install guide[/URL]. Coming from LineageOS 22.2: just continue below.
[*]Boot into Download mode and flash the [B]23.2 recovery from this release[/B]:
[CODE]samloader flash --partition RECOVERY recovery.img --no-reboot[/CODE]
The 22.2 recovery can't install 23.2.
[*]Unplug USB, hold Vol Down + Power until the screen goes black, then immediately hold Vol Up + Power to boot into recovery. Check that it says 23.2.
[*][B]Factory reset → Format data / factory reset.[/B] This also formats /metadata (OMR). Don't skip it.
[*]Apply update → Apply from ADB:
[CODE]adb -d sideload lineage-23.2-XXXXXXXX-UNOFFICIAL-gts4lvwifi.zip[/CODE]
Answer "Yes" if it says signature verification failed. Stopping at 47% with "adb: failed to read command: Success" is normal.
[*]Optional, Google Apps: Apply update → Apply from ADB again, then sideload [URL='https://github.com/MindTheGapps/16.0.0-arm64/releases/latest']MindTheGapps 16.0.0 arm64[/URL] [B]before the first boot[/B].
[*]Reboot system now. The first boot can take up to 15 minutes.
[/LIST]
[B]Never mix codenames:[/B] gts4lvwifi files are for SM-T720/T720N only, gts4lv files for the LTE models only.

[SIZE=5][B]LTE testers wanted[/B][/SIZE]
If you have an SM-T725/T727 and are willing to test, please first boot into any LineageOS recovery and run:
[CODE]adb shell ls -l /dev/block/by-name/omr[/CODE]
Post the output here. If the partition exists, the gts4lv build should install the same way. Report calls, SMS and mobile data. Logs help a lot: [I]adb logcat -b all -d[/I], and from recovery [I]adb shell cat /proc/last_kmsg[/I].

[SIZE=5][B]Reporting bugs[/B][/SIZE]
Please include your model, the build date, what you did, and logs ([I]adb logcat -b all -d[/I]; for boot problems, [I]/proc/last_kmsg[/I] read from recovery). Reports without logs are hard to act on.
