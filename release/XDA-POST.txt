[SIZE=4]Unofficial LineageOS 23.2 (Android 16) build for the Samsung Galaxy Tab S5e[/SIZE]

[SIZE=3]SM-T720 / T720N (gts4lvwifi) · SM-T725 / T725C / T725N / T727* (gts4lv)[/SIZE]


Android 16 needs kernel features a 4.9 kernel doesn't have (mainly modern eBPF).

This port has two parts: a [B]kernel backport[/B] (the ExyHyperBrick 4.9 eBPF series, about 2,450 commits) and a [B]full ROM[/B] (device tree, blobs and fixes for Android 16).

This is an [B]unofficial[/B] build made with AI to speed up the process.

It is not supported by the LineageOS team, so please don't report its bugs to them.

[SIZE=5][B]Known issues[/B][/SIZE]

[LIST]

[*]Screen casting (Miracast): fixed in the build, not yet confirmed on a receiver.

[*]ANT+ is not available.

[*]LTE models: no VoLTE / VoWiFi. Calls fall back to 2G/3G.

[*]Battery-usage wakelock statistics are incomplete (an SELinux label is still missing) and sleep works.

[/LIST]


[SIZE=5][B]Installation[/B][/SIZE]

⚠️ [B]A clean install is required. This erases all data on the tablet.[/B] Back up first, and remove your Google account from the tablet (Factory Reset Protection).

[LIST=1]

[*]Coming from Samsung stock: unlock the bootloader and flash vbmeta first, exactly as in the [URL='https://wiki.lineageos.org/devices/gts4lvwifi/install/']official install guide[/URL]. Coming from LineageOS 22.2: just continue below.

[*]Boot into Download mode and flash the [B]23.2 recovery from this release[/B] because 22.2 recovery can't install the 23.2 ROM:

[CODE]samloader flash --partition RECOVERY recovery.img --no-reboot[/CODE]

[*]Unplug USB, hold Vol Down + Power until the screen goes black, then immediately hold Vol Up + Power to boot into recovery. Check that it says 23.2.

[*][B]Factory reset → Format data / factory reset.[/B] This also formats /metadata (OMR). Don't skip it.

[*]Apply update → Apply from ADB:

[CODE]adb -d sideload lineage-23.2-XXXXXXXX-UNOFFICIAL-gts4lvwifi.zip[/CODE]

Answer "Yes" if it says signature verification failed. Stopping at 47% with "adb: failed to read command: Success" is normal.

[*]Optional, Google Apps: Apply update → Apply from ADB again, then sideload [URL='https://github.com/MindTheGapps/16.0.0-arm64/releases/latest']MindTheGapps 16.0.0 arm64[/URL] [B]before the first boot[/B].

[*]Reboot system now. The first boot can take up to 15 minutes.

[/LIST]

[B]Never mix codenames:[/B] gts4lvwifi files are for SM-T720/T720N only, gts4lv files for the LTE models only.
