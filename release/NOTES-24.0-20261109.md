Unofficial **LineageOS 24 (Android 17)** for the Samsung Galaxy Tab S5e. Install guide, status and known issues: [README](https://github.com/anton-scholten/lineageos-galaxy-tab-s5e#readme).

**Coming from 24.0-20261022, 24.0-20261026 or 24.0-20261105: update over the air** (*Settings → System → Updater*), no data is erased.

**What's new since 2026-11-05**
- **Volume panel opens again**: the settings button at the bottom of the volume pop-up did nothing in 24.0-20261105 (a regression in the November security update, fixed by LineageOS).
- Keyboard suggestion chips keep their size.
- Turning Bluetooth developer options on or off asks for the reboot correctly.
- More security fixes in Settings, and updated APN list.
- Latest LineageOS updates.
