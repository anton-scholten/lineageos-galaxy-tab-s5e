Unofficial **LineageOS 24 (Android 17)** for the Samsung Galaxy Tab S5e. Install guide, status and known issues: [README](https://github.com/anton-scholten/lineageos-galaxy-tab-s5e#readme).

**Coming from 24.0-20261019, 24.0-20261022 or 24.0-20261026: update over the air** (*Settings → System → Updater*), no data is erased.

**What's new since 2026-10-26**
- **Android security patch level 2026-11-01** (November 2026 security fixes from LineageOS).
- **Bluetooth security fix** for a heap overflow in the L2CAP layer.
- **App bubbles are available** (#5): apps can be opened as floating bubbles (long-press an app in the launcher or the taskbar). Android 17 hides them on tablets that support desktop windowing; this build keeps both.
- **3-button navigation is centred** (#6) when the taskbar is turned off, in portrait and landscape.
- Latest LineageOS updates (Settings, Wi-Fi, telephony, Launcher, apps).

Kernel `4.9.337-ga668db21f3cf`. Fixes owed upstream: [UPSTREAM.md](https://github.com/anton-scholten/lineageos-galaxy-tab-s5e/blob/main/UPSTREAM.md).
