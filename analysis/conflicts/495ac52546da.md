## Proposed resolution
MERGE — keep both sides of the block; do not take either side whole.
Final tail of `arch/arm/tools/syscall.tbl` should be:
```
396	common	pkey_free		sys_pkey_free
424	common	pidfd_send_signal	sys_pidfd_send_signal
434	common	pidfd_open		sys_pidfd_open
436	common	close_range		sys_close_range
```
i.e. keep ours' two `pidfd_*` lines, add theirs' `436 close_range`, and drop theirs' `397 statx`
(sdm670 has never had it; and `arch/arm` is not built for this arm64-only device, so the whole
`arch/arm/tools/syscall.tbl` is cosmetic here — `__NR_close_range` on arm64 comes from
`include/uapi/asm-generic/unistd.h`, which already merged).
Do **not** "fix" the ordering: `arch/arm/tools/syscall.tbl` is allowed to be non-contiguous here
(424 and 434 are already out of order relative to 395/396 in sdm670), so appending 436 at the end is
consistent with the file's existing state.

Prerequisite note: `SYSCALL_DEFINE3(close_range, ...)` lives in `fs/open.c` at series head
(`baa585f67e0e:fs/open.c:1206`) and is added by `d8bcd1ad1922` "BACKPORT: open: add close_range()"
(series position 1004, `CLEAN`; this commit is position 1006). Without that commit the new
`__SYSCALL(__NR_close_range, sys_close_range)` mapping will not link, so make sure `d8bcd1ad1922`
lands before or together with this one.
