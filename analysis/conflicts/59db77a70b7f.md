## Proposed resolution
MERGE — take **theirs** on the single block: `net/ipv4/tcp_ipv4.c` `lookup:` label becomes
`sk = __inet_lookup_skb(&tcp_hashinfo, skb, __tcp_hdrlen(th), th->source, th->dest, sdif, &refcounted);`
and drop the `ours` variant. Nothing else in this file is disputed; keep all auto-merged hunks.

Ordering caveat (important, do not skip): `inet_sdif()` is **not** part of this commit. It is added by
`b327d83996fc` "BACKPORT: net: ipv4: add second dif to udp socket lookups", which sits at series position
576, immediately before this commit at 577. That commit must be applied (and resolved) first, or
`net/ipv4/tcp_ipv4.c:1620` will not compile. The same `sdif` family continues with
`c11fb5bd8454` "BACKPORT: net: ipv4: add second dif to raw socket lookups" (position 582) and
`4087d4790a28` "bpf: Add helper to retrieve socket in BPF" (position 919) — resolve them as one group.
`include/net/ip.h` merges cleanly for `b327d83996fc`, so `inet_sdif()` itself is safe; only its
`net/ipv4/udp.c` hunk conflicts.
