## Why it conflicts
**Modify/delete on a generic, non-Exynos file - this one must NOT be dropped.** sdm670 deleted
(never had) `include/uapi/linux/android/Kbuild`; the series modifies it.

- `git ls-tree a30605a54f3b -- include/uapi/linux/android/Kbuild` -> empty (no such file)
- `git ls-tree c286cded153a^ -- include/uapi/linux/android/Kbuild` -> `100644 blob ca011eec252a` (the file predates the
  series; `git log --diff-filter=A d54533f1546b..baa585f67e0e -- include/uapi/linux/android/Kbuild` returns nothing)
- The change is one line: add `header-y += binderfs.h` next to the existing `header-y += binder.h`. That is the UAPI
  export list that installs `linux/android/binderfs.h` into the kernel headers.
- Nothing Exynos-specific is involved: `include/uapi/linux/android/` in sdm670 contains exactly one file,
  `binder.h` (`git ls-tree --name-only a30605a54f3b include/uapi/linux/android/`). sdm670 simply predates the
  per-directory UAPI `Kbuild` split, so "deleted" here means "written before that upstream refactor", not
  "deliberately removed for this board". This is the case where accepting the deletion would lose a needed file.
- Extra wrinkle the lead must know: creating the file is **not sufficient on sdm670**. The parent
  `include/uapi/linux/Kbuild` does not list the directory. sdm670's copy is only 40 lines and starts with
  `header-y += self_display/` (line 2) and never has `header-y += android/`
  (`include/uapi/linux/Kbuild` @ `a30605a54f3b`), whereas the Exy tree has `header-y += android/` on line 2 of the
  same file. So on sdm670 today `include/uapi/linux/android/binder.h` is not exported by `headers_install` at all.
  AOSP does not rely on `headers_install` (Soong's `android_kernel_headers` reads the header straight out of the
  kernel source tree), which is why 22.2 builds fine today - but if the lead wants the kernel's own
  `headers_install` to be correct, `header-y += android/` has to be added to `include/uapi/linux/Kbuild` too.

merge-tree on its own (`git merge-tree --write-tree --name-only --merge-base=c286cded153a^ a30605a54f3b c286cded153a`,
tree `ccf6fdf5f22235ee9bc3e349a475dd4c73547340`) reports 2 modify/delete conflicts: the `Kbuild` above **and**
