# a6b06e3852ea: BACKPORT: bpf: Support for setting initial receive window
## Summary
Adds `BPF_SOCK_OPS_RWND_INIT` and `tcp_rwnd_init_bpf()`, so a `BPF_PROG_TYPE_SOCK_OPS` program can set
the advertised receive window. sdm670 has none of it. The one conflict the trial saw is a single
argument in `tcp_select_initial_window()`. Watch out for a second one: taking the `tcp_minisocks.c`
block verbatim would declare `int mss;` twice and break the build.
