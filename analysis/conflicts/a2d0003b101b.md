1. `CONFIG_UCLAMP_TASK` / `CONFIG_UCLAMP_TASK_GROUP` do not exist in sdm670's Kconfig
   (`git grep 'UCLAMP' a30605a54f3b -- init/Kconfig kernel/sched/Kconfig*` -> nothing), so on the Tab

   UCLAMP_TASK_GROUP, so this is expected; flagging it so nobody reads "MERGE" as "feature enabled".

   the kernel tree. If Android 16's init writes `cpu.uclamp_min`/`uclamp_max` cgroup files (the
   CONFIG_UCLAMP_TASK_GROUP feature) and the kernel does not advertise it, those writes fail. The
   batch label `optional` comes from a keyword heuristic that matches neither `sched` nor `uclamp`, so
   I would not trust it for this commit - suggested lead check: `git grep -n uclamp` in a clone of
   `LineageOS/system_core` (libprocessgroup) and in `LineageOS/android_system_core` on lineage-23.2.
